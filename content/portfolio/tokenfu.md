TokenFu is a compact cross-platform toolbar UI for keeping an eye on API token usage and estimated cost.

<!--more-->

The panel shows current activity by model, including tokens per second, total tokens, cache use, and approximate spend, with today and history views for checking how a session is developing.  Each provider is represented by a small spinning coin.

TokenFu is written as a hardware-accelerated native UI, using Vulkan on Windows and Metal on macOS.  The goal is a small status display I can leave running while agents work.
