Asteroids is a fun and friendly game to build, mostly because every feature is visible the moment it works. This one is part of the MGFX teaching framework.

<!--more-->

The demo is designed to show simple game physics without hiding the interesting bits behind a full engine. It has ship thrust, momentum, collisions, wrapping space, and tweakable parameters so students can see how changing the physics alters gameplay.
