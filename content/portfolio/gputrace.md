I currently work on the Nsight Graphics Team at NVIDIA.

<!--more-->

Nsight Graphics is a frame debugger and profiler for modern graphics applications. GPU Trace is one of the features that helps developers understand what the GPU is doing over time: markers, workloads, stalls, cache and memory behaviour, and all the little clues that turn "it is slow" into an actual investigation.

There's a great talk about GPU Trace [here](https://news.developer.nvidia.com/what-is-limiting-your-rendering-performance/)

You can download Nsight Graphics [here](https://developer.nvidia.com/nsight-graphics).
