I currently work on Developer Tools at NVIDIA.

<!--more-->

For the last 7 years or so I've been working on tools for the Nintendo Switch. Before that I worked on GPU Trace and Nsight Graphics. Most recently I've been diving deep into Agentic programming, Dark Factory development and building skills to help our teams be more productive.

Nsight Graphics is a frame debugger and profiler for modern graphics applications. GPU Trace helps developers understand what the GPU is doing over time: markers, workloads, stalls, cache and memory behavior, etc.

There's a great talk about GPU Trace [here](https://news.developer.nvidia.com/what-is-limiting-your-rendering-performance/)

You can download Nsight Graphics [here](https://developer.nvidia.com/nsight-graphics).
