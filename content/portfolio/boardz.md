Boardz was a collection of turn based board games released for iPhone and iPad.  It included a server, player matching & chat.
<!--more-->

The host was written in C++ & Objective C, the server was Ruby On Rails running inside a Heroku host.

 Games available were:

- Chess
- Draughts
- Go
- Shogi
- Chinese Chess
