Recognizing gestures for a spell-casting game idea.

<!--more-->

This was fun, but I wasn't sure how to make it work in a real game.  The prototype captured strokes, normalized them, and tried to match the resulting shape against known gestures.  Players draw the same gesture in surprisingly different ways, so matching was less straightforward than it first appeared.  I learned quite a bit about the science of gesture recognition though.
