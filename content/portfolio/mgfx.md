Mgfx is a teaching framework I've used at York Developers. It has simple support for building 2D and 3D applications in C++, with cross platform support.

<!--more-->

Mgfx was my first foray into making an application that ran on Mac, Windows and Linux, and was easy to build from GitHub. I would do some things differently now, but it remains a handy tool for trying new ideas.

When combined with ImGui it is easy to make a new renderer and let the user pick parameters. The binary also lets you switch between the various demos, including a ray tracer, Asteroids, maze generation, Sponza rendering, and Game of Life. The point was to remove the boring setup work so students could get straight to the bit they came for.

[On GitHub here](https://www.github.com/cmaughan/Mgfx)
